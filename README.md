The official website of **Maximanu.DE**.

## About

Maximanu.DE is a personal and project website featuring information about current projects, websites and other online activities.

The website is built as a lightweight static website with a focus on a modern, responsive and clean design.

## Features

- Modern responsive design
- Automatic light and dark mode
- Responsive layout for desktop and mobile devices
- Reusable header and footer components
- Projects overview
- Contact page
- About page
- Imprint
- Privacy Policy
- Custom 404 page
- Bootstrap Icons

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
